Новые возможности.
Те же ваши данные.

Обновление 4.0 добавляет помощника по распределению, проверку планов и подключение внешнего ИИ. Без серверного подключения работает явно обозначенный локальный режим.

Перед обновлением: в прежнем приложении откройте «Ещё → Скачать резервную копию» и сохраните JSON в безопасном месте.

Закройте другие вкладки FINANCE OS, включая установленную версию на домашнем экране. Обновляйтесь в том же браузере, где вели записи.

Не очищайте данные Safari/Chrome, IndexedDB или localStorage. Не загружайте личный JSON на GitHub. Эта страница меняет только файлы приложения.

Версии 2.0 и 3.0 используют ту же базу. Новые разделы добавляются без замены счетов и операций. После обновления сверяйте остатки и сделайте новую копию. Банки и облачная синхронизация не подключены. Настоящий ИИ включается отдельно через сервер; без него работает локальный расчёт.
