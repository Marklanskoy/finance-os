# FINANCE OS 2.0 — файлы готового сайта

Это обновлённое приложение, не архив аудита. Сборка на GitHub не нужна.

## Заменить старую версию

1. Распакуйте этот ZIP. Загрузите его содержимое в корень прежнего репозитория `Marklanskoy/finance-os`, заменив одноимённые файлы. Не загружайте сам ZIP и не создавайте вокруг файлов дополнительную папку.
2. Не меняйте существующий адрес сайта и настройку GitHub Pages: ветка `main`, папка `/ (root)`.
3. Дождитесь успешной публикации в GitHub Actions.
4. Закройте все старые вкладки FINANCE OS. Откройте в Safari или Chrome опубликованную страницу обновления:
   `https://marklanskoy.github.io/finance-os/update.html`
   Нажмите «Открыть обновлённое приложение». Эта страница обновляет файлы приложения, а не очищает данные.
5. При обнаружении старой базы сначала нажмите «Скачать старую базу», сохраните JSON отдельно, подтвердите сохранение копии и затем нажмите «Перенести данные».

**Не очищайте данные Safari/Chrome, localStorage или IndexedDB. Не удаляйте репозиторий.**

На iPhone приложение запускается как опубликованный сайт, не через просмотр `index.html` в приложении «Файлы». Для домашнего экрана: Safari → «Поделиться» → «На экран Домой».

## Что изменено

- Светлая и тёмная темы в графитово-изумрудной палитре, мобильная навигация и боковая панель на компьютере.
- Точные денежные величины в минимальных единицах валюты; контроль переполнения. Все поддерживаемые валюты KZT, RUB, USD, EUR имеют в этой версии два дробных знака.
- Операции, отдельные переводы с комиссией, связанные возвраты, плановые записи, поиск и фильтры.
- Баланс, резервы на цели и остаток по плану — разные показатели с объяснением.
- Лимиты на конкретный месяц; исправленные суммы отчётов, отдельный учёт комиссий, процентов и погашений долга.
- Пополнение цели — виртуальный резерв существующих денег со счёта. Оно не создаёт доход и не двигает реальные банковские средства.
- Платежи по долгам связаны с журналом: изменение/удаление пересчитывает основной долг. Проценты вводятся вручную отдельно.
- Последняя операция отменяется только при неизменной ревизии. При конфликте вкладок устаревшее изменение отклоняется, а не перезаписывает новое.
- Подтверждение сохранения после завершения транзакции IndexedDB; черновик при ошибке, импорт/экспорт и пять локальных снимков.
- Пользовательские названия выводятся как текст, не HTML. Нет сторонних шрифтов, трекеров или языковых моделей.
- PWA-манифест, иконки и service worker с кешем, ограниченным приложением. Отдельная страница обновления для перехода со старого кеша.

## Перенос старой базы

Перенос предлагается из прежнего ключа `financeos1` на том же origin (домен, протокол и порт). Сначала записывается исходный JSON в страховочную копию; прежний localStorage не удаляется.

Новая база: IndexedDB `finance-os-v2:<путь приложения>`. Демо использует отдельное имя с суффиксом `::demo`.

Будущие операции старой версии становятся плановыми и перестают влиять на текущий баланс. Суммы старых целей хранятся как **неподтверждённые** до привязки к деньгам на счетах. Старые долги переносятся по их остаткам; исторические списания остаются обычными операциями, поскольку старая версия не сохраняла надёжную связь платежа с долгом. Закрытые долги также сохраняются.

**Обязательно сверяйте счета, валюту, накопления и остатки долгов после переноса.** Если раньше в старой версии менялся символ валюты без пересчёта, приложение не может автоматически восстановить правильные номиналы.

Если старая база содержит некорректные суммы или ссылки на несуществующие счета, перенос останавливается. Скачайте исходный JSON; не очищайте хранилище. Произвольные ошибочные значения не исправляются молча.

Не используйте старое приложение параллельно с новым: базы версий не синхронизируются. После переноса продолжайте работу только в версии 2.0.

## Что означают показатели

Баланс — сумма начальных остатков и подтверждённых движений по счетам.

Списания — расходы и погашения основного долга, проценты и комиссии, за вычетом возвратов в месяце возврата. Обычный перевод не является расходом.

Остаток по плану — баланс минус резервы на цели и внесённые неоплаченные обязательства до конца текущего месяца. Плановые доходы в него не включены. Это НЕ банковский доступный баланс и НЕ гарантия допустимой суммы трат: неполные исходные записи дают неполный прогноз.

Для первоначального ввода укажите остаток **до внесённых операций**. Если вы добавляете покупки задним числом, сверяйте итог с реальным счётом. «Сверить остаток» создаёт видимую корректировку, не фиктивный доход.

## Ограничения

- Локальное хранение. Нет облачной синхронизации, подключения банков и фоновых push-уведомлений.
- Одна валюта на базу: нельзя сменить символ существующих денег. Мультивалютные счета и конвертация ещё не реализованы.
- PIN — только блокировка интерфейса. База, черновики и JSON-копии не зашифрованы. Защищайте устройство и не публикуйте резервные копии.
- Учитываются существующие долги «я должен», без автоматических банковских процентов и полноценного графика амортизации. «Мне должны» и учёт выдачи/получения займов — отдельный будущий этап.
- Плановые операции добавляются вручную; автоматические серии подписок, перенос остатков бюджетов и финансовые рекомендации не имитируются.
- Сценарий срока цели основан на введённом взносе, а не обещании достижения или прогнозе инвестиционной доходности.
- Локальные снимки не защищают от удаления данных сайта/утраты устройства. Скачивайте внешние JSON-копии.

## Проверка

64 теста расчётов и миграции; 11 тестов контракта хранилища на модели; 21 сценарий/проверка интерфейса в Chromium с тестовым хранилищем; 5 проверок сборки, CSP и модели service worker прошли.

**Реальный IndexedDB, сквозной офлайн-запуск PWA и Safari на физическом iPhone в среде сборки не проверены.** Браузерные URL-переходы заблокированы политикой среды. Тестовый стенд не заменяет проверку на устройстве. Перед полным переходом проверьте добавление, редактирование, перезапуск и экспорт на копии своих данных.
